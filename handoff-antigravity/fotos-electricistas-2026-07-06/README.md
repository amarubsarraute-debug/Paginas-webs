# Fotos electricistas - entrega 2026-07-06

Usar la carpeta `entrega/` o el ZIP `entrega-fotos-electricistas-2026-07-06.zip`.

Dentro de `entrega/` hay una subcarpeta por negocio con:

- `fotos/`: fotos propias confirmadas o material de trabajo con fuente fuerte.
- `logos/`: logos, placas o piezas de marca separadas de las fotos de trabajo.
- `README.md`: resumen por negocio.

Archivos principales:

- `entrega/manifest.json`: inventario completo con fuente y estado por imagen.
- `entrega/FALTANTES_Y_ACCESO.md`: negocios que siguen con menos de 6 fotos y que necesitan acceso a Instagram/Facebook o mas fotos de Google Maps.

Criterio: no se incluyo material con telefono/pais no coincidente, fotos personales, stock generico, banners genericos ni mapas.
